## 审核范围与方法

本次审阅覆盖页面中的 12 项过敏反应/过敏性休克病历记录提示、完成度展示、摘要、隐私说明和项目文档。审阅依据包括项目现有 [REFERENCES.md](../REFERENCES.md)、NICE NG258、World Allergy Organization 2020 guidance，以及 Resuscitation Council UK 面向医务人员的 anaphylaxis guidance。

本次只评价记录质控工具的措辞、风险和基层工作流，不评价具体患者诊疗，不提供个体化诊疗意见。没有使用真实病历或患者身份信息。

## 总体结论

**确认结论：修改后可继续作为早期公开原型测试。**

12 项提示的四阶段结构总体合理，适合作为处置后病历复核的起点；页面也没有提供药物剂量或自动诊断。但当前界面存在可能被误解为“临床完整性已验证”“适合离线使用”或“全部列出的处置均为必做项”的措辞。完成下列高优先级修改前，不应宣称已完成临床验证，也不应作为机构制度、急救流程或实时决策工具使用。

| `trigger` | 保留并微调 | 记录可能诱因和暴露经过合理，但未知诱因不能为了完成清单而填写。 | 增加“未知时如实记录未知，不推定诱因”。 |
| `abcd` | 保留 | ABCDE 适合结构化回顾，且当前提示覆盖气道、呼吸、循环、意识及皮肤黏膜。 | 明确这是“记录已完成的评估”，不代表页面指导评估顺序。 |
| `vitals` | 修改 | “完整生命体征”过于绝对；并非每项在每个场景都同等关键。 | 改为“记录实际测得的生命体征、意识状态及复测时间”；避免单独以体温作为过敏性休克关键指标。 |
| `diagnosis` | 修改 | “严重程度”可能暗示已有统一分级或自动判定。 | 改为“记录临床判断依据、受累系统及危险表现”；不在工具内计算严重程度。 |
| `negative` | 修改 | 关键阴性体征对病历有价值，但容易模板化，也可能造成“无皮疹/无哮鸣音即可排除”的错误印象。 | 改为“如实记录已评估的关键阳性与阴性体征”，并突出阴性体征不能单独排除严重过敏反应。 |
| `epi` | 保留并微调 | 记录实际给药的途径、部位、剂量、浓度和时间合理；页面未给剂量。 | 标签改为“如已使用，记录肾上腺素给药细节”，避免工具替代指征判断。 |
| `support` | 修改 | 当前并列氧疗、体位、静脉通路和液体复苏，可能被误读为所有患者均应完成。 | 改为“记录实际实施的支持措施、时间及反应”，并注明仅按临床指征和本地流程。 |
| `adjunct` | 修改 | “应记录为辅助治疗”仍可能暗示糖皮质激素或抗组胺药应常规使用。 | 改为“如使用辅助药物，记录目的和时间；不得表述为替代或延迟一线处置”。 |
| `recheck` | 保留 | 复评时间、生命体征变化和症状变化是重要的记录追踪项。 | 避免由工具规定复评频率或时长。 |
| `observe` | 保留并微调 | 转归、交接及理由应可追溯，但工具不应给出固定留观时长。 | 明确“记录临床决定及依据”，不计算是否可离院。 |
| `education` | 保留并微调 | 复发警示、规避建议与随访记录有价值。 | 改为“记录实际提供的个体化告知及随访安排”，由本地流程决定具体内容。 |

## 界面与安全问题

### 高优先级

1. **“完成度”和“关键项目完整”可能造成过度保证。**  
   勾选比例只代表用户点击了多少提示，不证明记录真实、诊疗适当或病历完整。建议改称“核对进度”，并在 100% 状态显示“已逐项核对，仍需临床人员确认真实性与适用性”。

2. **“关键”标签未经独立验证。**  
   当前六项由项目内部标记为 critical，不能暗示这是权威指南确认的最低安全集。建议改称“优先核对（项目暂定）”，或在独立审核前取消二元关键标签。

3. **离线和本地运行表述与当前功能不一致。**  
   README 称“offline-first”，页面称“本地运行”，但离线 PWA 尚在 [Issue #3](https://github.com/cjjaijia-svg/primarycare-record-check/issues/3) 中。建议在实现并验证前改为“浏览器端处理；输入内容不主动上传”，并注明离线可用性尚未保证。

4. **增加“不得用于抢救中的实时决策”提示。**  
   当前“不替代临床判断”仍可能不足。建议明确本工具用于处置后或记录过程中的完整性复核，不得延误抢救、转诊或上级会诊。

### 中优先级

5. **剪贴板风险需要说明。**  
   “复制质控摘要”会把备注写入系统剪贴板。建议复制前再次提示不要录入患者身份信息，并说明剪贴板可能被其他应用读取。

6. **中国基层适用性尚未完成本地化验证。**  
   当前证据主要来自国际和英国指南。用于中国医疗机构前，应补充可公开核验的国内指南、法规和本地病历制度，不得把国外观察或转诊安排直接视为国内标准。

7. **“不保存数据”应精确描述。**  
   当前备注保存在页面内存直至刷新或清空，并可被复制到剪贴板。建议用“服务器不接收或持久化表单内容；页面刷新或清空后状态消失”替代宽泛的“不保存数据”，并在代码变更后重新核验网络行为。

## 可接受的现有设计

- 四阶段顺序“接诊与评估—诊断依据—处置记录—复评与转归”易于理解。
- 未提供肾上腺素剂量、自动诊断、固定观察时长或自动出院判断。
- 已反复提示不替代指南、制度和临床判断。
- 备注框和摘要均提示不要填写患者身份信息。
- 现有证据映射主动区分了指南明确要求与项目自定义的记录质量扩展项。

## 建议整改顺序

1. 修改“完成度/关键完整”及离线、本地运行表述。
2. 修改 `time`、`vitals`、`diagnosis`、`negative`、`support`、`adjunct` 六项措辞。
3. 增加实时抢救禁用提示和剪贴板风险提示。
4. 完成离线 PWA 后验证缓存、更新和隐私行为。
5. 补充中国语境下可核验的权威依据。
6. 收到真实外部反馈后，再更新独立临床审核状态。
